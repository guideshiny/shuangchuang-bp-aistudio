# 一、项目简介

# 1.1 商机来源

3—12 岁是儿童财商启蒙的关键时期，而优质的财商教育能够培养孩子全方面的财商能力，培养孩子正确的金钱观、价值观。现在很多父母为了孩子能有更好的未来辛勤工作，省吃俭用，却又为孩子花钱无度感到无可奈何。最终孩子们的生活质量提上去了，而家庭的生活质量、家庭理财水平却又下来了。这更提醒我们，儿童时期的理财是多么的重要。尽早系统性的理财教育，将是孩子们一生的财富。而根据我们在西安市发起的问卷调查，90%的家长希望并愿意有这样一门趣味课程来帮助孩子们合理理财。为此我们开展了对西安市内建设财商教育平台的营销及一系列流程的推广。

# 8、附近的小程序 提升品牌曝光率

在小程序当中，拥有一个“附近的小程序”功能，这项功能可以展示附近 5KM 的小程序，而且还是实时的，用户只要进入 5KM 范围，打开附近的小程序，就可以搜到。对于企业而言，若拥有小程序，就可以借助这项功能，将自己的品牌全天 24 小时展示在用户面前，从而提升自己品牌的曝光率。

# 9、与公众号结合 实现粉丝变现

小程序可以和公众号进行结合，例如在公众号的底部菜单或者公众号的文章中插入小程序链接，此时用户只需要轻轻一点就可以进入小程序，方便快捷。对于企业而言，若拥有自己的小程序，就可以将其与自己的公众号进行结合，从而将公众号的粉丝导流到小程序中，实现粉丝变现。这种直接导流的方式与其他方式相比，客户流失率会大大降低。

# 5.2.3 教育网络化大势所向

我们现在几乎很难找到一个产品，或者一个商业模式里是没有互联网因素的。如果还有的话，他们会被广泛地分布在四五六线的原生的土著的城市里的产品，但是那已经是一个极少数的概率。教育+互联网现已成为标配。无需再去怀疑，就是看谁能把这个标配和链条融合得很好。

BAT 等互联网巨头早已竞相进军教育培训行业，将“互联网+教育”做的风生水起，树立了行业标杆。如今，这股热潮不降反增，除传统的新东方、巨人教育等公司主动转型外，各种在线教育新锐公司也是层出不穷，遭到成本的热烈追捧，在线教育用户边界不断扩大。另外，各种线下教育培训机构招生时，已经不仅限于传统地做地推、发传单，开始使用互联网工具进行推广宣传，借助互联网的优势提高学校教学质量和管理效率。

# 5.2.4 结合高新科技，打造体验更好的教育产品

<!-- page:22 -->

教育产品作为教育的载体，如果仅仅是知识的陈列，总归是枯燥的。尤其是儿童教育产品，第一点是要吸引小朋友，要好玩。生活中我们不难发现，绝大多数小朋友都喜欢玩手机、iPad，这说明孩子对科技产品的兴趣要远大于传统的书本。才艺多的技术，可以开发小朋友对于内兴趣，会给儿童教育行业带来了新的机会和产业生态。点读机、学习机的红利时期已成为过去，必须要结合新的科技成果。所以利用微信公众平台和小程序，可以为孩子们提供一个更加具有吸引力的学习环境。

# 5.3.2. 重点细分行业前景分析

①. 学前教育

良好的人口规模以及 80、90 后的新一代家长促进学前教育市场的发展。随着 2015 年国家宣布的二孩政策全面放开以及国民生活水平的逐步提高，2016 年出生总人口达 1780 万，达到 2000 年以来的巅峰。预计到 2020 年学前教育适龄人口将超过 1.2 亿人，这将为学前教育的发展提供良好的人口规模基础，同时 80、90 后成为家长，他们对学前教育的投入也将更多，再加上幼儿园费用的增长，预计 2020 年整体学前教育市场规模将达到 8,000 亿元。

<!-- page:24 -->

财政预算支持学前教育的发展。从国家政策方面，据财政部披露的2018年中央财政预算显示，2018年教育支出预算为1,711.22亿元，比2017年执行数增加105.01亿元，增幅为6.5%。而其中以普通教育中的学前教育增幅最大，较上一年度增长35.6%。

目前，比如代表企业威创股份，它旗下的幼教品牌共拥有加盟幼儿园超过 4500 家，从市场占有率上来说，威创股份是目前幼教行业内管理幼儿园数量最多的公司。

②.K12 课外辅导

课外辅导市场空间大，复合增长达 9.2\% 。鉴于中国教育体制对学习成绩的重视，留给课后辅导的市场空间很大。据统计，截至2017年12月31日，中国有超过10万家K12课外辅导服务供应商，市场格局仍相对分散。根据在校学生整体人数及人均消费额度，预计整体市场规模2018年将达到4,331亿元，而到2020年预计超过5,000亿元，未来三年复合增长率达 9.2\% 。

# 六、竞争分析

在现代社会中，人们如何看待财富，拥有财富，支配财富无疑是其一个重要的能力。财商教育也是与智商、情商同等重要一大教育。

# 6.1 行业概况

财商，是一个人认识金钱和驾驭金钱的能力，是一个人在理财方面的智慧和财富创造能力。这种能力包括智慧、行动两方面。少儿财商理财教育指从小对孩子的理财能力的启蒙和开发。

家庭教育、学校教育和社会教育强调智商培养，忽视情商，财商教育则几乎为零。注重学历教育的后果是孩子赚取财富的低能力，也让他们对于自身学历和财富不能成正比而感到困惑，甚至因为财务问题而痛苦不安。等孩子们长大成人走上社会时，社会公共教育和培训也很少涉及财商理财教育，许多人还是完全依靠自己的悟性和生活磨练慢慢地去获得财商，这样就导致许多人必然要走弯路！

而在国外，实施财商教育已是很多人的共识。美国孩子从3岁就开始“实现幸福人生计划—财商课程”；法国孩子从三四岁也开始学习“家庭理财是大自然赐予的，其他的一切都要通过劳动获得”；犹太人的理财教育则告诉孩子：“如果你喜欢玩，就需要你赚很多钱，等赚到钱后，你就可以玩更长的时间”。

# 7.1.1 我国目前财商教育的现状

# 9.1 线上教育的发展趋势

1. 线上教育会在大量的领域几乎完全取代线下。比如成人技能（英语、电子、设计、营销、软件开发等等）。互联网教育对传统线下教育的冲击，完全不同于淘宝、京东对于线下实体经济的冲击，实物产品具

<!-- page:43 -->

有唯一性，无论线上买还是线下买，都需要生产出来才能销售，而互联网教育的课堂只要带宽足够，几乎是无限大的，所以是一次讲课，所有人只要乐意都可以获取该知识；

2. 线上教育的繁荣，会大大压缩教育行业整体经济规模。因为互联网产品无限复制性，讲课优秀老师对于自己讲课的金钱价值诉求显得如此渺小。另外，越来越多的人才涌向线上，讲课能力较强的人会形成较大竞争，根据供求关系所以单次听课成本会大大降低。线下教育场地租赁、活动安排费用几乎完全省去；
