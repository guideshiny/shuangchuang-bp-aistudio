# 前言

# 一、大痛点，我国院外心肺复苏急救成功率不足 4.5%

心肺复苏急救既是急救医学专业用语，也是现场救护的重要内容。据统计，我国每年大约有54万人死于心搏骤停，相当于每分钟就有1个人死于心搏骤停，其中80%的心搏骤停发生在医院以外。目前，我国院外心肺复苏的成功率不足4.5%，而发达国家可达47.5%，这一现状亟待改变。

# 二、抢时间，心肺复苏急救的“黄金四分钟”

大部分人认为，遇到心脏骤停患者，首选是拨打120。实际上，救护车到达时，患者已经基本失去了救活的希望，即使救活，也会有各种严重后遗症。心脏骤停患者如果到不到及时抢救复苏，4-6分钟后会造脑和其他人体重要器官组织的不可逆的损害。若及时采取正确有效的复苏措施，患者有可能被挽回生命并得到康复，因此心脏骤停后的心肺复苏（CPR）必须在现场立即进行。在医院内主要由医生来实施心肺复苏，但是80%的心脏骤停发生在医院以外，第一目击者是身边亲人、朋友、同事或陌生人，在遇到紧急情况时，能正确实施心肺复苏，就可以挽救一个生命，因此，如何提高心肺复苏急救效率与普及率对于拯救生命、促进健康中国建设具有重要意义。

# 三、普及低，目前我国心肺复苏普及率不到 1%

近年来，各级卫计部门、医疗机构、红十字会、急救机构及社会组织等以不同形式普及心肺复苏技术。培训已经遍布各地的政府机关、企事业单位、武警部队、各级学校、社区、医疗机构、紧急救护机构及人群密集场所。目前我国可以普及的人群为10亿人（15-65岁人群）。但由于各种培训质量也参差不齐，缺乏统一规范，加之急救过程中不可控因素较多，导致目前复苏培训达不到预期目标。因此，我国心肺复苏急救普及率不足 1\% ，远低于美国的 60\%

# 四、项目初衷，“5G直播+医护指导”提高复苏急救效率和准确度

海螺急救项目基于 5G 商用和互联网直播技术搭建远程急救快速响应平台。依托移动端平台连接急救医生和病患家属，针对心肺复苏等急救内容提供即时直播施救和医护响应式辅导，旨在缩短复苏急救“黄金四分钟”的响应时间，提高急救效率和急救准确度。

# 一、项目摘要

# 1.1、项目概念与概貌

海螺急救（域名 www.hailuo120.com），基于 5G 商用和互联网直播技术搭建远程急救快速响应平台。依托移动端平台（网页/小程序/APP）连接急救医生和病患家属，针对心肺复苏等急救内容提供即时直播施救和辅导，解决复苏急救中的“黄金 4 分钟”难题。

# 1.2、市场机遇与市场谋略

根据《中国心血管病报告 2017》数据显示：“我国每年由于心脏疾病猝死的人数多达 55 万人，每天猝死人数 1500 人左右，80%以上都发生在院外。” [1] 对于心脏骤停的患者，4 分钟内进行复苏者可能有半数患者被救活，又称“黄金 4 分钟”。

2019 年 6 月 6 日，工业和信息化部正式向中国电信、中国移动、中国联通、中国广电四家企业颁发 5G 牌照，5G 商用元年正式开启。5G 将催生更大数据流量，超大宽带和低延时将进一步促进直播业务的发展。

海螺急救依托移动互联网直播技术实现远程急救服务，旨在缩短复苏急救黄金四分钟的响应时间，提高急救效率和急救效果。

# 1.3、目标市场及发展前景

前瞻产业研究院数据显示，“2009年到2017年我国互联网医疗市场规模从2亿元激增至325亿元，复合增速高达 89\% ，预计到2020年我国互联网医疗市场规模有望达到900亿元。”[2]由此可见，互联网医疗可触达的用户规模将越来越大，而仅靠医生或相关从业人员在后台回答问题并不能满足日益增长的用户量。因此，企业需依赖直播、AR、VR等新技术优化问诊、远程医疗等产品的功能，从而有效提升医疗行业效率，扩大互联网医疗市场规模。

# 二、项目背景

# 2.1、海螺急救项目宗旨

海螺急救旨在通过 5G 无延时直播技术实现远程急救，为心脏病患和病患家属提供视频直播+医护辅导的远程医疗急救解决方案。项目的宗旨主要体现在三

<!-- page:6 -->

个方面：急救效率的提升、急救方法的准确、急救模式的转变。

急救效率而言，海螺急救以复苏急救“黄金4分钟”为切入点，通过“5G直播”快速找到远程医护人员（从打开海螺急救平台到成功直播连线医护人员，需要上游充足的医护人员在线对接），通过LBS位置技术快速发现周边AED机，通过提升心肺复苏急救效率来提高复苏急救成功率。

急救方法而言，传统远程急救依托电话语音口述，在复苏急救的过程中容易出现错误的情况，可能出现复苏方法不得当的问题。海螺急救依托视频直播技术帮助医护人员在手机端远程进行复苏指导，提升施救人员的复苏操作准确性。

急救模式而言，海螺急救将依托 5G 应用背景积极探索 VR、AR 远程沉浸式急救直播和 AI 急救指导的可能性，由可视化急救提升为可沉浸式急救的远程医疗解决方案；另一方面，通过业务积累与数据采集，建立急救用户图谱信息与电子病例，为医护人员在急救时提供参考。

# 2.3.2 行业动态：三级医院人满为患，基层医院床位闲置

# 1）急救平台分析

① 视救：120 自救互救系统

急视救是一个基于移动视频技术的120自救互救系统，当病人呼叫120以后，120调度中心会显示病人位置、同时根据交通情况会自动排序出到达现场最快的急救网点医院，该医院急诊科医生会进入视频，对患者进行视频指导，同时派出救护车按照现场传递回来的疾病需求带好相应物品前往，医院可实时查看救护车位置、病人情况，进行提前准备。

缺点：无法及时赶到事发地点，容易错过黄金急救时间。

②First Responder

First Responder 是一个美国心肺复苏紧急救援平台，能够帮助心脏骤停患者在医务人员赶到之前，获得周围受过心肺复苏培训的人的救助，操作人员通过 GPS 来搜索并通知患者周围受过心肺复苏培训的人，并指引其到达事故发生地，为患者进行心肺复苏。

<!-- page:27 -->

缺点：响应慢，容易错过黄金急救时间。

# 2）急救培训

# ①红十字会培训

面向医疗从业人群、普通群众提供线下医疗急救的基本培训。包括心肺复苏、创伤救护等初级应急救护的核心知识与技能；常见急症、意外伤害、突发事件的处置要领（根据学员需求选择培训内容）。

缺点：线下培训覆盖面小，培训时间短，学员往往缺乏急救实践。在应急现场容易出现急救员因紧张等原因忘掉急救规范，出现复苏操作失误等急救事故。

②第一反应：切入急救救助与培训领域

第一反应是一家紧急救助培训服务提供商，为用户提供开设急救培训课程、完善赛事保障服务体系、急救资源共享等解决方案，致力于以商业方式解决公共急救资源匮乏的社会问题。

缺点：商业化培训在医疗急救培训方面缺少医疗资质，培训专业程度存在隐患。而且偏向于体育等细分领域，对实际院前急救培训应用率极低。

# 5.2.3 项目的差异化策略

# 5.2.4 海螺急救的竞争优势

海螺急救基于 5G 应用直播技术建立竞争壁垒，为急诊医护人员和心脏病患家属提供无延时的远程急救平台，提升远程心肺复苏急救的效率和准确度。

# 5.4、市场营销策略

据统计，我国每年大约有54万人死于心搏骤停，每天约1500人死于心搏骤停，相当于每分钟就有1个人死于心搏骤停，其中 80\% 的心搏骤停发生在医院以外。目前，我国院外心肺复苏的成功率不足 4.5\% ，而发达国家可达 47.5\% ，这一现状亟待改变。目前来说，民众对于急救知识(如心肺复苏CPR、AED机操作等)的掌握是贫乏的。

海螺急救的 5G 急救通话平台产品要打开国内市场，首先要寻找目标市场，然后进行精准的市场定位。项目通过对 4P 营销模型的分析，找到了开拓北京急救需求市场的突破口——对复苏急救的科普和推广。

# 5.4.1 产品策略：打造技术核心优势

海螺急救基于 5G 应用直播技术为心肺复苏急救提供“即时直播+远程场景化指导”策略。

# 1）构建金字塔产品梯队

海螺急救基于 5G 应用直播技术为心肺复苏急救提供“即时视频通话+医护指导+周边 AED 机”为核心，以急救中心对接为关键，以急救科普、急救培训线下对接为辅的产品策略。

通过这几项经营策略的实施，海螺急救按照金字塔产品梯队，将其系列产品划分为三个梯度细分策略，即核心业务为第一维度，关键业务为第二维度，衍生业务为第三维度。

# 5.4.2 价格策略：会员费+打赏抽成为主

# 1）定价内容

海螺急救是一款具有急救功能的平台产品，远程急救作为一种特殊的商品，主要有两个方面的原因影响其定价，即紧急急救业务和非紧急急救业务。

# i 紧急急救业务

因考虑急救服务以救人为主，所以海螺急救不考虑以此业务盈利。没有设置定价机制，而是开通了打赏功能，即用户（病患家属或者施救人员）通过海螺急救完成急救后，对参与急救的医护人员的打赏（注意：①此打赏非必要，完全由用户自由决定；②打赏金额随机或由用户自主设置）。

# ii 非紧急急救业务

# 九．风险分析

# 9.1、院外急救事故风险

院外急救事故风险是指患者或者家属对急救过程或结果不满意而引发的追责或赔偿问题。由于院外急救场所的开放性、复杂性、院外医疗处置的局限性、突发病情的不可预测性，导致院外急救风险的增加。

# 1）急救响应不及时，延误黄金急救时间

急救响应不及时包括急救人员发现事故晚、急救车到达不及时等问题，导致病患无法在第一时间接受急救治疗。

# 2）人员配置或抢救物品准备不足

根据 2017 年 3 月 1 日起实施的《北京市院前医疗急救服务条例》第三十条规定，对急救车上人员配置进行了具体规定，每辆院前救护应当配齐包括驾驶员、医师、护士、担架员等急救人员，具备为有需要的患者提供搬抬服务的能力。但院外急救的第一参与人并不是救护车，而是家属或现场群众，在这种情况下因人员配置不足或抢救物品准备不够导致的急救事故。

# 3）急救技术不佳或操作不当

对于心脏骤停患者，施救人员未及时进行心肺复苏、除颤、建立静脉通路等高级复苏方法，是认定赔偿责任的重要原因之一。院外场景的施救人员不是专业的医护人员，无法按照规范的医疗处置原则，比如对心搏骤停者未及时进行心肺复苏、生命体征观察不当，或急救中心线下参与急救过程中未对患者进行心率、血压、血氧饱和度等指标监测。

<!-- page:46 -->

# 4）医疗文书书写不规范

院外急救病例记录是整个院外急救过程中最直接最完整的反映, 是诉讼中的重要证据, 如果急救中心医生不按时书写病例, 书写内容不规范甚至杜撰虚假内容（将责任推到家属或现场群众）, 都是日后产生纠纷的重大隐患。

# 海螺急救的规避策略

# 9.2、市场风险

由于院外心肺复苏属于急救属性强、发生概率偏低的需求，所以海螺急救切入的是低频市场，与市场上其它拥有稳定需求、市场容量可以预计的普通消费商品是不同的。特别是发生突发事件（溺水、中暑、户外受伤等）后产生了即时院外急救需求，事前是无法估算出来的。加之项目目前没有用户基础，潜在用户群可能对心肺复苏的认知偏低等问题，所以说项目前期可能会存在市场拓展不开，主要风险如下：

# 1）低频需求

用户访问量小，流量太小，急救直播无人使用或医护人员无人响应，出现急救事故，导致医护人员或用户对海螺急救平台失去信心。

<!-- page:47 -->

# 2）平台打开率低

医护人员没有培养直播和远程急救场景的急救习惯，可能对人机交互模式的远程急救接受度低；

# 3）非成熟的心肺复苏急救市场

心脏复苏急救知识普及率在英、美等发达国家高达50%~80%，在我国仅为1%左右。公众生命安全与急救知识的匮乏已经成为不可忽视的问题，加强公众的“自救互救”认知迫在眉睫。我国部分大城市已经陆续开启了全民心脏复苏的普及工作，但大部分民众应急意识仍然淡薄，政府并没有强制规定应急培训的要求，没有产生强制约束性。

风险资金，其目的是通过在项目初期进行投资，换取较高的投资收益，如若退出时机选择不当，无论是对公司，还是对投资方而言，都会造成巨大的损失，因此，风险投资的退出，也是企业经营潜在的风险。
