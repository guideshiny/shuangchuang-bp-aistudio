# 第一章 执行概要

# 1.1 产品概要

全方位智能搬运机器人设计主要是为了在需要到仓储货运的行业充当搬运者，可以智能抓取、智能自身室内定位，凭借抓手的高自由度。实现灵活智能搬运，帮助仓储行业解决目前叉车搬运不够智能，不够灵活的问题；相比于需要导轨这些外设的搬运机器人，也更有实用性，不局限于外部设备的辅助。

# 1.2 项目背景

“十三五”期间，国家对起重机械领域的指导方针是“安全、智能、绿色”，智能起重机就是大型机器人。随着“中国制造2025”战略的实施，无人化的全自动码头、无人化的全自动车间开始试点，起重机械正在向大物流跨界、正在向柔性加工系统跨界。

国家在中国工业4.0和中国智能制造2025规划中明确提出：“要促进基于互联网的物流新设备、新模式、新技术出现和发展，从而大幅提高物流效率。”物流自动化指的是在物流的各个环节，以自动化设备、软件及控制系统代替人工进行生产作业的新生产模式。物流行业则是以仓储为中心，其业务的根本目的在于降低流通成本，提高货物流动的效率。而对于以系统论、信息论和控制论为基础的现代物流，自动化是市场的必然选择。但是目前行业发展仍处在相对早期，产业集中度较为分散。一方面，在国内市场，外资企业和国内自动化装备企业形成错位竞争，国内企业受产品质量不高、自动化程度低等方面限制，导致整体行业爆发力被削弱。开发智能物流仓储设备、提升快递物流装备自动化水平是每个国内自动化物流企业的首要目标。

据前瞻产业研究院发布的《中国智能物流行业市场需求预测与投资战略规划分析报告》统计数据显示，中国智能搬运市场规模更是呈现高速增长状态。截止至2020年中国智能搬运市场规模增长至5850亿元，初步测算2022年中国智能搬运市场规模将突破7930亿元，达到7900亿元左右。并预测在2025年中国智能搬运市场规模将达12280亿元。

本项目基于智能控制技术设计一款适用复杂环境下的高效率搬运机器人。通过“工”字型底架设计、多自由度的抓手装置、全自动智能控制等技术，实现全方位智能搬运。

# 第二章 市场分析

# 2.1 国内状况

我国搬运机器人的发展较晚，虽然在制造理论、工艺及成套设备已有重大突破，但仍缺少原创性、系统性的深入研究。国内对于机器人的研究主要以个大高校为主体，浙江大学的朱秋国教授创立的云深处科技，推出的“绝影”智能机器人系列，实现了复杂环境下的步态行走，缩小了与世界前沿国家的差距。企业方面，南江机器人公司也已自主研发了智能调度系统Robot IDS、智能移动机器人、智能仓储机器人、智能SMT上下料机器人、智能作业机器人等，其中智能移动机器人IAGV Pro-F采用激光+二维码定位导航，初步实现了机器人的自动搬运，且根据不同需求最大负载可达800KG。2020年12月，上海新时达工厂首次实现全机器搬运，使其相比与传统工厂用工量减少了 80\% ，产品测试一次性通过率上升 15\% ，单位面积产出效率提高了 30\% 以上。我国目前的智能搬运机器人仍与西方发达国家存在一定差距我国搬运机器人在如何控制低成本导航、提高仓储运输物流效率、提升复杂环境下的搬运能力等方面的技术还处于落后水平。

# 2.2 国外状况

西方发达国家对于物流自动化领域的研究开展得较早，因此欧、美、日、韩4个家在此领域的发展更加快速，也更加成熟。2021年3月，波士顿公司，推出了新的自动化仓配机器人Sretch，可以自动执行混合SKU托盘堆叠和卸垛，车身上安装了车载视觉系统能够跟踪带有标记的托盘进行导航，抓手采用了吸盘式抓取，吸盘的形状会根据作业的不同有所改变。韩国IRIM LAB实验室研发的LIMS2-AMBIDEX的抓取部分采用欠驱动机械抓手-BLT抓手，通过外侧刚性结构作为抓取驱动，内侧柔性结构作为抓取交互，实现了抓取压力的均匀分布，抓手整体抓取载荷达15KG。目前国外的物流机器人在效率、稳定方面已经趋于完善，但在精度、自动化和过载方面的技术仍有欠缺。

# 2.4 行业痛点

传统搬运方式主要以人力搬运和叉车搬运为主，但这种方式费时费力，工作效率低，安全性差，目前一些公司研发的智能搬运叉车，能够解决工作效率低，安全性差的问题但这种新型叉车的转向半径大在仓储运输过程中，通过叉车将物料放入不同高度的货架时，由于仓库的空间有限，驾驶者需要频繁操作进行转向，同时为了避免货物发生掉落或碰撞货架，驾驶者需要缓慢移动搬运车而造成的时间浪费等问题。

# 三、社会分析

# （一）全球范围技术进步将开启智能物流新时代

智能物流是利用集成智能化技术、智能设备等使物流系统能模仿人的智能，具有思维，感知，学习，推理判断和自行解决物流中某些问题的能力。在世界范围内，随着物联网、机器视觉、仓储机器人、无人机等新技术的应用，物流自动化技术正在以较快的速度发生变革。我们认为，物流领域是自动化技术发展最活跃、进步最迅速的板块之一，并且海外先进技术正在向国内外溢，进一步刺激国内物流自动化率快速提升。近年来，物流自动化主要技术创新包括三大方向：KIVA式“货到人”拣选，高效分拣抓取和无人货物配送。

# （二）“货找人”订单拣选：实现对传统仓储作业的颠覆

电商快递业的迅速发展将带动“货到人”智能设备的需求。我们认为如何实现订单的高效精准拣选和快速响应，是电商仓储物流发展所面临的关键问题。近两年来以亚马逊为主的主流电商快递龙头企业纷纷加大对仓储自动化技术的投入，不断加大创新，如亚马逊推出的KIVA机器人，实现货找人的订单拣选，国内外一些企业纷纷在KIVA的基础上陆续推出“货找人”订单拣选系统，如海康威视最近推出的阡陌系统，以达到成本的节约和效益的提升。

# （三）分拣机器人：实现无人机仓储最重要的一步

<!-- page:18 -->

机器人拣选作业是由机器人来进行品种拣选，如果品种多，形状各异，机器人需要带有图象识别系统和多功能机械手，机器人每到一种物品托盘就可根据图象识别系统“看到”的物品形状，采用与之相应的机械手抓取，然后放到搭配托盘上。分拣抓取机器人要进入市场仍需一段时间，一旦这些智能化的分拣机器人应用于电子商务、工厂、物流等行业，将极大地提高仓储管理的工作效率，压缩人工成本。

# （四）货物配送：无人机和机器人都将成为可能

无人机送货可以实现同城物流的加急业务和偏远地区快递业务，进一步开辟物流行业的细分市场，使物流网点、终端之间的流转获得更高效率，提升企业在配送领域的竞争能力。另一方面，庞大的快递队伍以及用工难已经成为众多快递企业发展的一大障碍。而无人机送货，在运营成本大幅降低后，可以实现大量人力的节约。近两年来，亚马逊、顺丰、京东、淘宝等主流电商快递企业纷纷开始进行无人机配送的实地测试。机器人送货，2015年11月，Skype旗下的Starship公司推出了一种专门用来小件货物配送的“盒子机器人”。“机器人盒子”配置了一系列摄像头和传感器，99%都是的自动操作，能够安全行走在人行道上，会在指定时间从物流中心出发，穿越大街小巷，来到顾客家门口完成快递任务。经过3000小时的测试之后，2016年3月，该种机器人将首先在纽约实现交付使用，计划在2017年启动全面商业运作。

# 四、技术分析

从全球来看，自动化物流系统的产生和发展是社会生产和科研技术发展的结果，并伴随着劳动力成本、土地成本的增加等而得到迅速发展。与传统物流系统相比，新技术新应用大大提升企业经营效益与效率，形成对传统生产作业模式的一种颠覆：货物配送；

# 1、提高生产与配送的效率和准确性

自动化物流系统采用先进的信息管理系统、自动化物料存储、分拣和搬运设备等，使货物在仓库内按需要自动存取与分拣。

# 2、实现企业信息一体化

物流信息化是企业信息化重要组成部分，物流信息管理系统通过与企业其他管理系统无缝对接，实现信息在企业的各个系统之间自动传递与接收，使企业实

现信息一体化，避免物流系统成为“信息孤岛”，对供产销全过程进行计划、控制和物料跟踪。

# 3、提高物流管理水平

自动化物流系统可以对库存的入库、出库、移库、盘点等操作进行全面的控制和管理，不但反映了物品进销存的全过程，而且可对物品进行实时分析与控制，为企业管理者作出正确决策提供依据，平衡企业生产、储存、销售各个环节。

未来新技术新应用的普及将带动物流从自动化走向智能化。智能物流是利用集成智能化技术、智能设备等使物流系统能模仿人的智能，具有思维，感知，学习，推理判断和自行解决物流中某些问题的能力。智能物流的未来发展将会体现出四个特点：智能化，一体化和层次化，柔性化与社会化。

随着中国物流应用市场的不断拓展，包含物流机器人在内的细分市场得到更大的关注。搬运、码垛、分拣、AGV等均属于物流机器人行业，它们已经在为工厂的自动化物流仓储改造贡献力量。而在世界范围内，随着物联网、机器视觉、仓储机器人、无人机等新技术的应用，物流自动化技术正在以较快的速度发生变革。

目前来看自动化领域巨头们纷纷加大在物流自动化的创新，为新的制造和物流应用场景提供解决方案，加入人工智能、数据分析等新的技术提升，主要出现三类创新方向。

# (1) “货找人”订单拣选

随着物流业的发展，物件的位置、摆放方向、种类、形状和大小也越来越多样，通过采用视觉识别技术给机器人“装上眼睛”，实现货架找人的订单拣选，如亚马逊的 KIVA 机器人。

# (2) 分拣抓取机器人

机器人依据订单完成物品的拣选，这一方向对机器人视觉识别技术要求非常高，目前这一方向也面临着一些挑战和机遇，主要体现为是否能为客户提供达标的识别准确度和精度以及满意的性价比。

# (3) 无人送货系统

主要分为无人机和机器人系统，解决物流最后一公里问题。目前亚马逊、谷歌、京东等纷纷加大在一方向的投入。

# 4.1.2 细化市场

市场细分是指营销者通过市场调研，依据消费者的需要和欲望，购买行为和购物习惯等方面的差异，把某一产品的市场整体划分为若干消费者群的市场分类过程。全方位智能搬运机器人主要依赖于中国的物流程序，销售市场可以扩大到全国范围。

# (1) 地理变数

按地理变数细分市场就是把市场分为不同的地理区域，如国家、地区、省市、东部、西部、南方、北方、城市、农村、山区、平原、高原、湖区、沙漠等。以地理变数作为市场细分的依据，是因为地理因素影响消费者的需求和反应。由于全方位智能机器人不参与快递的运输过程，不涉及运输过程的地理变数。然而智能化的产品一般出现在一线或者二线城市，因此我们在考虑地理变数时，会把市场放在比较发达，有条件承担智能化的城市。

# (2) 人口变数

人口变数细分是按年龄、性别、家庭人数、生命周期、收入、职业、教育、宗教、民族、国籍、社会阶层等人口统计因素，将市场细分为若干消费群体。全方位智能搬运机器人是为了所有网上购物的顾客服务，人口涉及层面广，主要以当地的企业情况为主。

# (3) 心理变数

在市场营销活动中，常常出现这种情况，即在人口因素相同的消费者中间，对同一商品的爱好和态度截然不同，这主要是由于心理因素的影响。市场细分的心理因素十分复杂而广泛，涉及消费者一系列的心理活动和心理特征。主要包括消费者的个性、生活方式、社会阶层、动机、价值取向、对商品或服务的感受或偏爱、对商品价格反应的灵敏程度以及对企业促销活动的反应等。下面我们就其中的部分因素加以说明。

# 1、生活方式

生活方式是指个人或集团在消费、工作和娱乐上表现出的特定的习惯。不同的生活方式往往产生不同的消费需求和购买行为，即使对同一种商品，也会在质量、外观、款式、规格方面产生不同的需求。如今网上购物，电商等购物方式已经成为人们日常购物方式，加快物流速度和物流智能化有利于适应人们的生活方式的改变。

# (4) 行为变数

行为细分是根据消费者对品牌的了解、态度、使用情况及其反应而将他们分为不同的群体。许多营销人员认为：行为变数是市场细分的最佳起点。

# 第六章 经营管理

# 6.1 组织结构

# 一、工作专业化

一个人不是完成一项工作的全部，分解成若干步骤，每一步骤由一个人独立去做。就其实质来讲，工作活动的一部分，而不是全部活动。我们的团队有明确的分工，尤其实在全方位智能搬运机器人的开发研究中全权交予开发者，管理者并不过多的干涉。

# 二、部门化

根据地域进行部门划分，由于全方位智能搬运机器人并不依赖于当地的环境情况，所以我们并不进行部门地域划分，而是进行职能的划分。

# 三、命令链

同样，随着电脑技术的发展，日益使组织中任何位置的员工都能同任何人进行交流，而不需通过正式渠道。而且，权威的概念和命令链的维持越来越无关紧要，因为只能由管理层作出的决策，授权给了操作员工自己作决策。

# 四、控制跨度

加宽控制跨度，与各个公司努力降低成本、削减企业一般管理费用、加速决策过程、增加灵活性、缩短与顾客的距离、授权给下属等的趋势是一致的。但是，为了避免因控制跨度加宽而使员工绩效降低，公司加强了员工培训的力度和投入。

# 五、集权与分权

我们采用集权式管理，组织的层级化是指组织在纵向结构设计中需要确定层级数目和有效的管理幅度，需要根据组织集权化的程度，规定纵向各层级之间的权责关系，最终能形成一个能够对内外环境要求做出动态放映的有效组织形式。

# 六、正规化

制定相关的制度以保证公司产品的正规化。员工需要遵守管理人员制定的一系列详尽的规章制度。尤其是在全方位智能搬运机器人的研发过程中应该严格遵守规章制度防止某些重要信息的泄露。

# 第七章 公司战略

# 7.1 总体战略

公司确立了 3 年引进，3 年扩张的发展战略。在公司发展的前三年里，将以成都市为基础，提高公司的品牌形象及影响力，并将业务范围扩展到全省。在第二个三年阶段，公司将抢占以湖北为中心，辐射全国的市场，以点到面，先是在全国其他六大区域的中心城市进行布点，再逐步向区域内进行覆盖，力争使其成为国内领域内的领导者。

# 7.2 发展战略

公司预计在 2022 年开始运行，具体分三个阶段：

1. 初期战略（2022年-2025年）于2022年注册成立智能AGV运输公司，主要营销地区选择为华中地区，主要针对汽车制造业、物流业、烟草行业。锁定华中产业较为集中的地区（如：湖北武汉、湖北长沙等），积极打开潜在市场推广我们的产品，争取有利地位。

目标分析：公司成立三年内，公司作为刚起步的行业新入者主要以开拓市场为主，集中向有较大且稳定需求量的工厂进行产品推广。目标市场集中化也可以达到品牌效应，以一个点的良好反映带动一片的周边市场的拓展，从而进一步扩大知名度。

2. 中期战略（2025年-2027年）仍锁定汽车制造业、物流业和烟草行业，将地域有华中地区辐射至全国。在华中地区销售情况已经较为稳定的情况下，开始向国内其他区域渗透（仍采取集中渗透的方式），从而增大公司产品的覆盖面、扩大市场份额。

<!-- page:67 -->

目标分析：在综合前三年的发展经验之后，我们公司已趋于成熟壮大，逐渐形成自己完整的产业链，营销链。此时凭借之前开拓的市场，以及成熟的营销，对于 AGV 尚未得到普及的潜在市场，我们便可以优势进入。保持在原有涉足的行业进行技术突破，稳定市场份额。

3. 远期战略（2027年及之后）突破传统行业，向医药、港口等其他应用领域进军。稳中求进，实现产品多元化，并能为不同的客户提供个性化产品定制。

目标分析：针对与医药、港口、化工等生产厂家和互联网购物物流日益发展的局势、我们将完善我们的产品，及时进行产品优化。并在技术上不断创新，根据不同的客户需求定制最合适的 AGV，提供自动化物流解决方案的服务，从而在打开市场的同时也建立良好的商誉。

# 附录五：团队总结及感谢

我们团队经过几个月的学习和制作，整理积累了机器人设计过程中的三维模型，程序，元器件的挑选和购买，实物的制作和程序调试过程。每一次团队合作也是一个相互学习的过程，这个学习不仅仅是涉及项目知识的快速学习，而是学习他人优秀的品质。通过这次团队合作，自己可以认识很多优秀的人，通过他们，意识到自己的不足，每个人都有自己的优点，我们只有虚心请教他人，才能使自己快速成长。而且国外机械行业还是较我们发达，自己不能局限于中文资料。参加这种比赛，也可以锻炼一个人的意志力，因为我们只能利用业余时间做这种比赛，所以娱乐的时间少，项目的完成进度经常会和学习考试发生冲突，自己必须在短的时间内，学习新的内容，从而提高了自己办事的效率。以前可能对机械结构观察不深入，接触的机械产品太少，具体到设计过程中时，大脑中浮现的机械结构太少，只能根据产品功能去查阅书籍。所以我认为对于机械专业学生，必须生活中留心观察各种机械结构，了解工作原理，存储在大脑中，这样设计产品才能得心应手。有了一定机械知识的存储，才会从中得到灵感，才能有好的创新点子。

前期我们进行机械结构的优化设计，设计更可靠稳定的机械结构，以保证机体的更高效，更稳定的进行货物搬运和更轻量化的设计。其次，优化手抓结构，寻找一种更简单更高效的抓手，来进行货物的抓取和放置，并具有更高的可靠度。之后进行程序的优化和机器人的搭建及测试调试。将全部程序编写好并进行试运行，购买电子元器件和进行部件加工，最后组装，搭建电路及程序调试。大学里工科类学生必须注重实践，通过动手实践，可以加强我们对大学所学知识的综合运用，提高自己的动手能力和思维能力。

在此感谢团队每位成员的付出和努力，感谢一起努力奋斗的日子，感谢老师们的尽心认真地指导，最后感谢“互联网+”主办方对此次项目的重视和支持，给了我们一个向上拼搏的机会。
